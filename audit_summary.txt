5. frontend/src/features/giveaways/hooks.ts has no active consumer; it appears tied only to the unmounted Giveaway UI.
6. frontend/src/features/http.ts is a small, unreferenced re-export facade. External downstream use is not searchable in this private repo.
7. backend/requirements.txt declares Flask-Migrate without any import, initialization, CLI command or migration directory in the scanned code/docs. Confirm deployment tooling before changing dependency declarations.
8. backend/crud/character.py duplicates CRUD operation names from the live character_crud module, but external imports cannot be ruled out.
9. frontend Profile CSS retains selectors from a replaced layout; selectors look unused in literal source, but static CSS analysis is heuristic and dynamic class generation exists elsewhere.
10. backend/test.txt, _verify_avatar.py and backend/tmp_* files are locally ignored; merge_report.txt explicitly records that the three image fixtures were intentionally left on disk. Treat these as owner-held local artifacts, not routine cleanup.
